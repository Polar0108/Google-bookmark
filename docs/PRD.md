# Visual Bookmark 产品需求文档

## 1. 背景与问题

Chrome 原生书签栏和书签侧边栏主要依赖标题、图标和文件夹层级。用户积累大量书签后，很难仅凭标题回忆网页内容，也很难在浏览当前网页时快速浏览已有收藏。

Visual Bookmark 的目标不是替代 Chrome 的数据体系，而是为原生书签提供一个可视化、可搜索、可整理的扩展侧边栏。

## 2. 产品定位

### 目标用户

- 经常收藏研究资料、产品案例、设计灵感和技术文章的重度用户。
- 拥有数百至上万条书签，并依赖 Chrome Sync 保存书签层级的用户。
- 希望在浏览网页时快速查看和打开书签，而不是跳转到独立管理页面的用户。

### 核心价值

1. 通过截图和标题快速识别书签。
2. 在当前网页右侧完成浏览、搜索、收藏和常用整理。
3. 保留 Chrome 原生书签的同步能力和可迁移性。

### 明确边界

- 扩展不能向 Chrome 自带书签侧边栏注入按钮或替换其列表，因此产品使用独立的扩展侧边栏。
- 首版不覆盖新标签页。
- 首版不提供账号、云端截图、团队协作、AI 摘要或正文归档。
- 首版仅支持 Google Chrome 116 及以上版本。

## 3. 核心体验

### 3.1 打开侧边栏

- 用户固定 Visual Bookmark 的扩展图标。
- 点击图标展开扩展专属侧边栏；再次点击同一图标收起侧边栏。
- 侧边栏与当前网页并列，用户可以通过 Chrome 的分隔线改变宽度。
- 扩展使用 `ResizeObserver` 感知内容区域宽度，不能主动改变 Chrome 侧边栏宽度。

### 3.2 侧边栏结构

从上到下依次为：

1. 搜索框。
2. 当前范围导航：范围名称、数量、排序、列表/视觉模式切换、更多菜单。
3. 文件夹路径或文件夹快捷入口。
4. 书签内容区。
5. 固定在底部的“添加当前标签页”按钮。

### 3.3 两种展示模式

列表模式：

- 接近 Chrome 原生书签的紧凑体验。
- 展示 favicon、标题和文件夹。
- 文件夹可展开或进入。
- 适合快速定位和管理。

视觉模式：

- 默认两列卡片。
- 只有内容宽度小于 `280px` 时变为一列。
- 宽度继续增加时，卡片保持约 `128px` 的最小宽度并增加第三列、第四列；第四列为上限，之后均匀放大四列卡片。
- 卡片封面固定 `16:10`，使用 `object-fit: cover`。
- 卡片展示 favicon、域名、两行标题和文件夹/标签；侧边栏中不展示长描述。
- 卡片整体高度可以因标题行数略有差异，但图片比例固定。

视觉模式使用响应式网格排列，列数由容器宽度自动决定。

### 3.4 宽度规则

| 内容区宽度 | 展示 |
| --- | --- |
| `< 280px` | 一列视觉卡片 |
| `280–415px` | 两列视觉卡片 |
| `416–551px` | 三列视觉卡片 |
| `>= 552px` | 四列；达到下一列阈值后仍固定四列并放大卡片 |

卡片间距为 8px；内容区左右留白为 8px。极窄状态隐藏文件夹标签和次要操作，只保留截图、网站图标和标题。

### 3.5 文件夹与范围

- 默认范围为“全部书签”，聚合所有原生书签。
- 顶层文件夹以紧凑快捷项显示，不作为截图卡片。
- 进入文件夹后，标题行显示返回按钮和当前文件夹名称。
- 视觉模式只展示网址书签，子文件夹继续使用紧凑快捷项。
- 搜索结果跨全部文件夹，并显示每条书签的所属路径。

### 3.6 打开书签

- 普通点击：在当前活动标签页打开。
- `Cmd/Ctrl + 点击` 或中键：在后台新标签页打开。
- 打开成功后记录本地 `lastOpenedAt`，用于“最近使用”排序。
- 不写入或伪造 Chrome 浏览历史。

### 3.7 收藏当前页面

用户点击底部按钮后：

1. 读取当前标签页 URL、标题和 favicon。
2. 在用户授权有效时提取站点名、description 和 Open Graph 元数据。
3. 截取当前标签页可见区域。
4. 将截图中心裁切为 `16:10`，缩放至最大 960px 宽，编码为 WebP。
5. 显示确认浮层：标题、文件夹、标签和封面预览。
6. 创建 Chrome 原生书签，再写入本地视觉元数据。

权限或截图失败时仍允许创建文本书签，使用 favicon 与站点色占位封面。

重复 URL 规则：

- 比较时忽略 fragment，保留 query。
- 找到一条匹配时，默认更新该条的封面和元数据。
- 找到多条匹配时，让用户选择目标文件夹或明确创建副本。

### 3.8 常用管理

MVP 支持：

- 修改标题与 URL。
- 移动至原生文件夹。
- 新建文件夹。
- 删除书签，操作前明确确认。
- 添加或移除本地标签。
- 重新截取、上传或清除封面。
- 多选后批量移动、标签和删除。

首版不支持复杂规则、失效链接扫描和重复清理。

## 4. 状态与异常

- 首次安装：解释原生侧边栏限制、权限用途和本地存储方式。
- 无书签：展示创建或收藏当前页入口。
- 无封面：favicon + 域名首字母 + 站点色占位。
- 无搜索结果：保留关键词并提供清除操作。
- Managed Bookmark：标记为只读，禁用修改和删除。
- `chrome://`、`file://`、扩展页和受保护页面：无法提取时降级，不阻塞文本收藏。
- 隐身模式：首版不持久化任何数据。
- 数据库损坏或封面缺失：原生书签仍可展示，不影响打开和管理。

## 5. 成功标准

- 10,000 条书签下首次加载可在 1 秒级显示骨架和首批内容。
- 本地搜索在 100ms 级返回结果。
- 视觉模式在正常 Chrome 侧栏宽度下稳定保持两列。
- 原生端创建、修改、移动和删除后，打开的侧边栏在 500ms 内更新。
- 截图失败不会造成书签创建失败或原生数据不一致。
- 扩展卸载后，Chrome 原生书签保持完整。
