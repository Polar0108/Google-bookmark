## 覆盖范围

- 280px 精确断点、极窄一列、常规/宽侧栏两列、列表固定一列。
- URL fragment 规范化与完整书签树重复检测。
- 标题、文件夹和标签搜索；10,000 条数据查询性能保护。
- 16:10 中心裁切计算。
- 卡片打开与多选行为。
- 原生书签无需尺寸测量即可渲染为完整卡片，避免卡片被压缩为 0 宽。
- 截图操作验证必要的网站访问权限。
- 截图在侧边栏直接完成，不通过 runtime message 传输大尺寸图片；捕获失败会显示实际原因。
- 缺失封面优先从网站公开的 Open Graph 预览图补全；不可用时生成稳定的本地暗色站点封面。
- 添加当前标签页时立即捕获可见区域；普通点击书签不会创建或替换封面。
- 卡片提供手动更新封面按钮，并通过注册域规则允许同站点子页面/子域名、拦截其他网站。
- 手动刷新立即捕获当前可见状态，不再执行页面加载、字体、图片或稳定状态等待。
- “所有书签”标题右侧提供批量刷新按钮，可重新处理全部网站封面；底部不再重复显示批量按钮。
- 底部添加按钮采用暗色圆角、显式边框与裁切保护，避免边角黑色缺口。
- 列表模式固定使用网站 favicon；多选模式使用独立左侧选择列，不覆盖图标。
- 自定义排序菜单覆盖选择、关闭和无障碍状态；设置按钮在新标签页打开选项页。
- 远程预览元数据使用纯文本白名单提取，不创建外部 DOM；ChatGPT 等网站的脚本和 modulepreload 标签不会再触发扩展 CSP 错误。
- 消息结构验证与危险 URL 拦截。
- 标签规范化。
- IndexedDB 存储统计、只清封面、书签删除联动清理。
