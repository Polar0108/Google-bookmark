# Visual Bookmark 安装与验收

## 开发者模式安装

1. 执行 `pnpm install` 与 `pnpm build`。
2. 在 Chrome 打开 `chrome://extensions`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择项目中的 `.output/chrome-mv3` 目录。
6. 在扩展菜单中固定 Visual Bookmark。
7. 打开一个普通网页，点击工具栏图标；右侧应出现 Visual Bookmark 专属侧边栏。

## 核心验收路径

1. 在工具栏切换“列表”和“视觉”模式。
2. 将侧边栏调整到 280px 以下，视觉模式应为一列；拉宽后应依次在约 280px、416px、552px 显示两列、三列、四列，并继续自动增列。
3. 安装或重新加载时允许网站访问。点击“添加当前标签页”，确认出现 16:10 截图预览，选择文件夹与标签后保存。
4. 在 Chrome 原生书签管理器中确认同一条书签存在。
5. 修改、移动、删除原生书签，确认侧边栏同步更新。
6. 测试搜索标题、域名、文件夹和标签。
7. 测试编辑、上传封面、清除封面、新建文件夹、批量移动/标签/删除。
8. 从 Chrome 侧边栏和扩展工具栏两种入口打开，均应可以读取当前网页并保存截图。
9. 点击“所有书签”标题右侧的刷新按钮，确认全部网站封面逐步重新加载；有公开预览图时使用预览图，否则生成包含网站图标与名称的本地暗色封面。
10. 点击无封面和已有封面的书签，确认普通打开都不会创建或替换封面。
11. 在同一网站的子页面点击卡片底部刷新按钮，确认当前可见画面立即成为新封面；切换到其他网站再点击时应被拦截。
12. 切换到列表模式，确认左侧只显示网站 favicon；进入多选后复选框位于独立左侧列，不覆盖图标。
13. 打开排序菜单，确认菜单紧贴按钮、背景不透明、图标对齐且没有蓝色选中描边。
14. 点击设置按钮，确认设置在新标签页打开且原网页未被覆盖。
15. 设置页中清除封面或全部增强数据，原生书签不得被删除。

## 打包

执行 `pnpm zip`。Chrome Web Store 上传文件位于 `.output/visual-bookmark-0.1.10-chrome.zip`。

## 开发命令

- `pnpm dev`：开发模式。
- `pnpm check`：TypeScript 与 ESLint。
- `pnpm test`：自动化测试。
- `pnpm build`：生产构建。
- `pnpm verify`：连续执行检查、测试与构建。
- `pnpm zip`：生成商店压缩包。
