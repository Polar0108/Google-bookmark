# Visual Bookmark 开发与验收计划

## 1. 交付目标

从空工作区交付一个可通过开发者模式加载、可构建 Chrome Web Store 压缩包、拥有自动化测试和完整上架文档的 Manifest V3 扩展。

每一阶段只有在代码、测试、文档与验收项同时完成后才可标记完成。

## 2. 阶段计划

### 阶段 A：工程与规范

- 建立 WXT、React、TypeScript 工程。
- 配置 Manifest V3、side panel、action、options 和 background 入口；使用按需脚本注入代替常驻 content script。
- 配置 ESLint、TypeScript、Vitest、Testing Library 和构建命令。
- 建立设计令牌、基础图标和中英文消息。
- 产出 PRD、架构和隐私文档。

验收：安装依赖后 `check`、`test` 和空功能 `build` 均通过。

### 阶段 B：原生书签数据层

- 封装 `chrome.bookmarks` 的读取、搜索、创建、更新、移动和删除。
- 将书签树扁平化并生成 folder path。
- 处理 managed/unmodifiable 节点。
- 监听全部相关书签事件并同步 UI。
- 使用 Dexie 建立元数据、封面和迁移表。
- 清理 orphan metadata/assets。

验收：模拟 Chrome API 的单元测试覆盖 CRUD、移动、删除文件夹、import 和事件丢失恢复。

### 阶段 C：侧边栏浏览体验

- 实现搜索、范围标题、数量、排序和视图切换。
- 实现列表模式与文件夹导航。
- 实现视觉卡片、固定 16:10 封面和占位封面。
- 使用虚拟化 lane 渲染大型数据集。
- `<280px` 一列，280px 起两列，并按最小卡片宽度增加到三列、四列；四列封顶。
- 实现当前标签页/新标签页打开规则。
- 持久化视图和排序设置。

验收：在 260、279、280、320、416、420、552、600px 内容宽度下验证自动列数。

### 阶段 D：收藏与截图

- action 图标使用 Chrome 原生行为切换侧边栏展开/收起，并记录授权的 tab/origin。
- 实现当前页元数据提取。
- 实现可见区域截图、16:10 中心裁切、960px WebP 压缩。
- 实现确认表单、文件夹选择、标签和重复 URL 分支。
- 权限拒绝、受限页面和截图失败时降级为文本书签。
- 确保原生书签成功后，本地元数据失败不会反向删除书签。

验收：普通网页、重复 URL、权限拒绝、导航后授权失效、受限协议和图片失败均有确定结果。

### 阶段 E：管理、设置与引导

- 单条编辑标题、URL、文件夹、标签和封面。
- 删除确认与批量操作。
- 设置页展示存储空间、主题、默认打开方式和隐私说明。
- 支持清理所有封面但不删除书签。
- 首次引导解释扩展侧边栏与 Chrome 原生侧边栏的区别。
- 中英扩展元信息与浅色/深色主题；0.1.0 产品界面以中文为主。

验收：所有破坏性操作有确认；卸载影响说明准确；无封面、无数据、无结果和错误状态完整。

### 阶段 F：质量与发布

- 单元测试覆盖纯逻辑、仓储层和截图计算。
- 组件测试覆盖模式切换、宽度切换、搜索和确认表单。
- 集成测试覆盖 mock Chrome API 事件链。
- 执行 TypeScript、Lint、Test、Build 和 Zip。
- 检查 Manifest 权限最小化、CSP、远程代码和隐私披露。
- 准备商店描述、权限理由、测试安装说明和发布清单。

验收：所有自动化命令通过；无高优先级审核问题；打包产物可供加载和上架。

## 3. 测试矩阵

### 数据

- 0、1、100、1,000、10,000 条书签。
- 深层文件夹、空文件夹、同名文件夹和重复 URL。
- managed bookmark 和缺失 dateAdded 的节点。
- 原生端增删改移动、import 开始/结束和快速连续事件。

### 布局

- 260/279px：一列。
- 280/320/415px：两列。
- 416/420/551px：三列。
- 552/600px 及更宽容器：固定四列，宽度继续增加时放大卡片。
- 标题 0、1、2 和超长多语言文本。
- 有封面、无封面、损坏封面和不同来源封面。
- 浅色、深色、200% 缩放和键盘导航。

### 收藏

- 有效 http/https 页面。
- 页面导航前后授权变化。
- chrome/file/data 页面。
- 截图成功但 metadata 失败。
- 书签成功但 IndexedDB 失败。
- 单条和多条重复 URL。

### 安全与隐私

- HTML/script 字符串只按纯文本显示。
- 无远程脚本、无 analytics、无 Cookie 权限。
- 页面临时权限只由用户点击扩展图标触发，不申请全站 host 权限。
- 清除封面不影响原生书签。

## 4. 完成定义

一项任务只有同时满足以下条件才算完成：

- 行为符合 PRD。
- TypeScript 无错误。
- 对应测试通过。
- 错误和空状态已处理。
- 权限与隐私影响已记录。
- 不引入未说明的外部网络请求。
- 验收矩阵中对应项目已复核。

## 5. 最终审核

最终交付前执行三轮审核：

1. 产品审核：入口、展示规则、交互和降级路径是否符合 PRD。
2. 工程审核：数据一致性、错误处理、性能、测试和构建是否可靠。
3. 安全发布审核：权限、CSP、隐私披露、商店材料和压缩包是否完整。

审核发现的问题必须修复并重新运行相关检查，不允许只记录不处理。
