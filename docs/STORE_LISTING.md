# Chrome Web Store 上架材料

## 名称

Visual Bookmark

## 简短说明

在 Chrome 侧边栏中，用网页截图、标题和文件夹快速浏览与整理原生书签。

## 详细说明

Visual Bookmark 为 Chrome 原生书签增加一个本地优先的可视化侧边栏。

主要能力：

- 列表模式与双列视觉卡片自由切换。
- 使用当前网页截图生成固定 16:10 封面。
- 搜索标题、网址、域名、文件夹、描述和本地标签。
- 新建文件夹，编辑、移动、删除与批量整理原生书签。
- 上传、重新截取或清除本地封面。
- 自动跟随系统的浅色、深色主题及默认打开方式设置。

Chrome 原生书签仍是标题、网址和文件夹的唯一数据源。扩展不会覆盖新标签页，也不会修改 Chrome 自带书签侧边栏。截图、标签与增强元数据保存在本机，不上传到开发者服务器。

## 权限理由

- `bookmarks`：展示并执行用户明确发起的书签创建、编辑、移动和删除。
- `activeTab`：用户点击扩展图标时，临时读取当前标签页并生成封面。
- `scripting`：在已临时授权的当前页面提取标题、URL、description 和站点名。
- 网站访问：用于捕获用户当前页面截图，并在用户主动点击“重新加载全部网站封面”时读取书签网站公开声明的 Open Graph / Twitter 预览图。
- `sidePanel`：显示扩展专属侧边栏。
- `storage`：同步布局、排序和主题等小型设置。
- `favicon`：通过 Chrome 内置 favicon 机制显示网站图标。
- `unlimitedStorage`：在本地 IndexedDB 保存用户主动创建的截图封面。

扩展不申请 Cookie 权限、浏览历史权限或远程代码权限。网站内容只在截图或用户主动补全封面时读取。

## 数据披露建议

- 处理网站内容：仅用户主动收藏时的标题、基础 meta 与当前可见区域截图。
- 处理用户活动：读取并管理用户的 Chrome 书签。
- 数据用途：单一用途为视觉化书签展示、搜索和整理。
- 数据传输：不传输到开发者服务器，不出售，不用于广告或信用评估。

## 商店素材清单

- 128×128 扩展图标：已包含。
- 1280×800 或 640×400 商店截图：发布者需在真实 Chrome 中拍摄，建议包含双列侧边栏、收藏确认和设置页。
- 隐私政策公开 URL：发布者需补充。
- 支持邮箱：发布者需补充。
