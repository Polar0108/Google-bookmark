# Visual Bookmark 隐私政策（草案）

Visual Bookmark 使用 Chrome 书签数据，为用户提供本地视觉书签侧边栏。

## 处理的数据

- Chrome 原生书签的标题、URL、文件夹和时间信息。
- 用户主动收藏页面时的网页标题、描述、站点信息和当前可见区域截图。
- 用户创建的本地标签、封面和界面设置。

## 使用方式

- 书签数据用于在侧边栏展示、搜索和整理用户书签。
- 页面元数据与截图用于创建视觉封面。
- 设置用于保留用户选择的布局、排序和主题。

## 存储与传输

- 截图、标签和增强元数据只保存在用户设备上的扩展存储中。
- Visual Bookmark 不提供开发者服务器，不上传或出售用户数据。
- Visual Bookmark 不使用书签、页面内容或浏览活动投放广告。
- Chrome 原生书签是否通过 Chrome Sync 同步，由用户的 Chrome 设置决定，不由本扩展控制。

## 权限

- 书签权限用于读取和修改用户明确操作的原生书签。
- activeTab 与 scripting 用于用户主动收藏当前页面时读取基础元数据和生成封面。
- 网站访问权限用于捕获当前页面截图，以及在用户主动点击“重新加载全部网站封面”时读取书签网站公开声明的预览图片与描述。扩展不会读取表单、Cookie 或登录凭据。
- sidePanel 用于显示扩展侧边栏。
- favicon 用于显示网站图标。
- unlimitedStorage 用于保存本地截图封面。

## 删除

- 用户可以在设置中删除全部本地封面和增强元数据，而不删除原生书签。
- 卸载扩展会删除扩展本地数据，但不会删除 Chrome 原生书签。
